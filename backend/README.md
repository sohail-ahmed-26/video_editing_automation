# Studio Backend Service

Backend service for autonomous video and photo editing workstation.

## Overview
The backend powers the editing pipeline, handling:
- Video ingestion, audio demuxing, and transcode processing.
- Speech automated transcription and timestamp alignment.
- Semantic cut decision generation based on user natural-language prompts.
- Color grading, silence removal, dynamic zoom framing, and caption burn-in.
- Video timeline rendering and output export.
